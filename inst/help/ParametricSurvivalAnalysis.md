# Parametric survival

Ancillary parameter models start with no predictors, including when adding a location model. Assign their terms independently; existing selections are retained.

When ancillary regression is enabled, the location model is titled with its native parameter: rate, scale, meanlog, or mu. Selecting multiple distributions shows their distinct location parameters; ancillary model titles identify the corresponding non-location parameters.

Advanced specification is available only when that parameter's models contain predictors. Removing their predictors disables its controls while retaining the checkbox's saved state. Adding predictors restores availability.

Disabling ancillary parameter regression fits location-only models. Retained ancillary terms, transformations, and coefficient restrictions are excluded from fitting, validation, and predictor requirements. Location transformations and restrictions, and globally fixed baseline parameters, still apply. Re-enabling ancillary regression restores its retained configuration.

Model predictions share Plot and Table controls across the selected measures. Survival probability and failure probability can be selected independently or together, with confidence bounds computed for each measure. Lifetime / Time displays predicted lifetime against the lifetime percentile, scalar mean/median estimates without an X grid, or time-based outcomes against elapsed time or the RMST horizon. A predictor x-axis displays selected percentiles, times or horizons across its observed range; categorical axes use points and bounds.

Assign **Lifetime / Time** to exactly one role: X-axis, Separate lines, or Separate plots. Replacing Time on X with a predictor puts Time in Separate lines unless it is already in Separate plots. Time on X retains the full-curve evaluation settings. Time in lines or plots uses independent sparse values: lifetime percentiles 25, 50 and 75, or times at 25%, 50% and 75% of zero to the maximum finite observed follow-up. Plots determine this maximum across the fits displayed together, so merged subgroup plots share the same physical times. Each table uses its own fit's follow-up. These defaults are editable; blank custom times use those same three range values. Numeric predictor plots use 101 observed-range values; tables have a separate predictor count, default 10. Factor predictors use their levels.

Merge tables across measures combines the selected survival probability, failure probability, hazard, cumulative hazard and restricted mean survival time at common times or horizons. The probability Y-axis scale applies only to survival and failure probabilities: Log uses base 10, and Log(-log(1-p)) transforms the displayed probability. Each numeric predictor has its own X-axis transformation and plotting range, applied across its prediction outcomes.

Separate lines and plots use every factor level or the raw mean in each continuous quantile group. The default is three groups; one group uses the overall mean. Ties stay together and empty groups are omitted. Unassigned predictors use the selected Average, Default or Custom values within the actual fitted subgroup. Fitted transformations and polynomial bases are retained; display roles do not refit models.

Each coefficients table combines baseline parameters and regression coefficients within the selected model, distribution, and subgroup grouping. With ancillary regression enabled, every regression label includes its native parameter, for example `[scale] x` and `[shape] x`. Baseline estimates remain on their natural scale; regression coefficients act on the native link stated in the footnotes. Baselines refer to zero fitted design terms, which need not mean zero raw transformed covariates. Treatment and SAS have zero categorical design at the omitted reference level; Sum, Helmert and Polynomial contrasts can have a baseline that does not correspond to one observed category.

Fitted model equations are shown after the coefficient tables, with models in rows and native parameters in separate columns. Tables combining distributions use numbered columns (Parameter 1, Parameter 2, and so on), in each distribution's native parameter order; the equation identifies its parameter. The number of columns matches the largest number of parameters in the displayed distributions. Equations use predictor names and factor levels directly. Parameters with regression terms show their native link; constant parameters are reported on their natural scale. Fixing a baseline does not remove its regression terms.

Equations retain fitting transformations, temperature conversions, factor contrasts and polynomial bases. Fitted coefficients are rounded for display only. Very small nonzero coefficients use scientific notation. Predictions always use unrounded coefficients and the original fitted basis.

**Predictor specification** keeps covariate transformations, including Natural log (`ln(x)`), General log (`c * log(x, base = y)`), Power (`x^y`), and Root (the y-th root of x), alongside Scale, Reciprocal, Arrhenius, Eyring and Polynomial. General log defaults to multiplier 1 and base 10; multiplier -1 supplies the former negative-log operations. Power and Root both default to 2, providing square and square root. Compact formula inputs accept expressions such as `3/2`. Fitting and predictions use evaluated numbers; coefficient labels and displayed equations retain the entered expressions. Zero multipliers, exponents and root degrees are rejected. Odd integer root degrees allow negative predictors; other invalid transformation domains produce fit errors.

Factors offer Treatment (dummy), Sum, Helmert, Orthogonal polynomial and SAS contrasts independently in each model and parameter equation. Treatment is the Advanced specification default. Treatment and SAS have a Reference selector containing only the factor's levels. The first level in the dataset's category order is selected initially for both codings; selecting another level omits that category instead. Polynomial contrasts use the retained category order and equally spaced rank scores, regardless of numeric-looking labels. Factor assignment never applies numerical transformations. Fixed factor slopes follow the displayed contrast-coefficient order.

The location equation defines each model's raw default factor profile; an ancillary-only factor uses its first effective parameter equation. Treatment/SAS use the selected reference, while Sum/Helmert/Polynomial use the first retained training level. Every parameter equation evaluates that same raw profile with its own coding. Default predictions, plots and blank Manual/Dataset factor cells use it, and output notes identify the selected level. Explicit Custom levels and Average weighting are unchanged. Changing coding alone with all categorical slopes free preserves the fitted distribution at the same raw profile; selecting a different default profile can change default predictions.

**Arrhenius (eV): 1/(k_B T)** uses reciprocal absolute temperature divided by Boltzmann's constant, `k_B = 8.617333262145179e-5 eV/K`. Output labels use `Arrhenius(T) [eV]`; source-temperature units remain in the model settings. The transformed predictor has units of inverse eV. In a log-lifetime equation without temperature interactions, its coefficient is activation energy in eV; for a log-rate equation, activation energy is the negative of this coefficient. Interactions and ancillary-parameter equations require interpretation on their model link. Fixed Arrhenius regression coefficients are specified on this same eV scale. Eyring retains its reciprocal-Kelvin `1/T` term and structural log-temperature term. Compared with the former `1/T` Arrhenius transformation, the Arrhenius slope and its standard error are multiplied by `k_B`, while the modeled temperature effect is unchanged. Rerun saved analyses to refresh the fitted output.

Natural cubic spline is available for continuous predictors, with degrees of freedom defaulting to 3. Knots are placed automatically from the fitting data and embedded in the fitted formula; new-observation predictions reuse that basis, with linear tails beyond the boundary knots. Each basis coefficient is reported separately. The same transformation is available in location and ancillary equations, including interactions. This transforms a predictor; it does not replace the baseline survival distribution with a spline model.

For Weibull, scale is characteristic life (63.2% failure); mean and median also depend on shape. For lognormal, exp(meanlog) is median lifetime; mean additionally depends on sdlog. For exponential, mean lifetime is 1/rate. A negative Gompertz shape gives positive survival at infinity, so unrestricted mean lifetime is infinite; use RMST for a finite horizon. With ancillary regression, location coefficients do not automatically define a common acceleration factor for every percentile.

The Bounds drop-down in Confidence interval selects uncertainty for every model-based interval. Table headings show 95% CI for two-sided intervals, 95% Lower Bound for lower bounds, or 95% Upper Bound for upper bounds, using the selected confidence level. At 95%, two-sided intervals use the 2.5th/97.5th simulation percentiles, lower bounds use the 5th percentile, and upper bounds use the 95th. Each confidence level keeps its own coverage. One-sided plots show the estimate and one dashed bound curve; two-sided plots use ribbons. Empirical Kaplan-Meier intervals remain two-sided.

Confidence levels, direction, and display precision update output without changing model fitting. Prediction intervals share joint native parameter draws across measures, times, scenarios, and confidence levels. Fixed coefficients have no estimated standard error or interval; finite predictions from a fully fixed model have bounds equal to the estimate. Existing boundary and unavailable-covariance restrictions still apply.

For one-component Generalized F (original) Eyring models with right-censored input consisting entirely of exact events, uncertainty uses analytic density information at the fitted estimates. Other models retain native information. Unusable information leaves estimates available and reports why confidence intervals are unavailable. Retained fits refresh information without refitting when their native metadata are sufficient; otherwise rerun the model. Retained fitting errors are retried only when fitting inputs change or the analysis is rerun.

Kaplan-Meier overlays require fixed factor-only effective equations in every displayed model, including models without predictors; unused factors averaged on the link scale have no matching empirical curve. Each overlay matches all effective factor values in its reference scenario. Continuous location or ancillary predictors have no matching empirical reference curve; observed marks remain available. Kaplan-Meier overlays use the same step curves, line width, and confidence-band opacity as non-parametric survival plots. Their colours match the standalone Kaplan-Meier palette; fitted model curves use separate colours.

**Predictions** has one **Predict for** selector: Variables, Manual input, Missing outcomes (dataset), or CSV file. All modes share outcome selections, lifetime summaries, evaluation grids, Plot/Table, confidence intervals and styling. Variables shows predictor assignments, unassigned reference values and assigned covariate values. Manual input replaces those controls with an add/remove-row observation table. Dataset and CSV modes hide them; CSV uses the file selector. Switching modes retains entered settings but ignores inactive specifications. Predictor-axis assignments, contours, relative survival time and empirical overlays apply only to Variables.

Observation predictions reuse the selected fitted models without refitting. Percentile curves use Lifetime percentile on X; survival probability, failure probability, hazard, cumulative hazard and RMST curves use Time on X, with one series per observation. Mean and median use individual observation numbers on X and estimates with confidence bounds. All curves follow the selected grid range and shared axis scales. Figures precede tables. Lifetime summary tables are wide by observation; time tables are long by observation and time/horizon, and Merge tables across measures combines the timed outcomes. Optional prediction intervals on mean/median plots show fitted event-time variability, separate from confidence intervals.

Missing-outcome predictions require a missing outcome and at least one specified predictor value before defaults; partially open intervals remain recorded outcomes. Manual expressions and blanks use fitting-data means or default factor levels. CSV input requires matching headers, finite values, supported factor levels and subgroup columns, without blank defaults. Export predictions to dataset is available only for Missing outcomes; exported values retain original row alignment, with missing values for ineligible or unsupported rows.

Dataset exports preserve original rows, with missing values for excluded or unsupported observations. All export producers are preflighted together before writes. An existing same-analysis column refreshes only with a matching stored semantic signature; otherwise choose a different prefix or remove the column.


Plot type selects **Curves and points** or **Contour**. Curves and points plots numeric predictors as curves and categorical predictors as estimates with bounds. Selecting multiple X-axis predictors creates a batch of separate one-dimensional plots. **Combine predictor plots**, above Legend in Display, arranges that same batch together; predictions and tables do not change.

**Relative survival time** is an independent outcome measure beside Survival time. Select a predictor x-axis and use the same Lifetime summary selections for both outcomes. It is the reference summary divided by the same summary at the plotted predictor value, within the same line and panel settings: percentile ratios, median ratios, or mean ratios. A ratio of 2 means the reference percentile is twice the current percentile. Ratios can vary by percentile with ancillary regression. Confidence intervals use paired parameter draws. Relative survival time is unavailable for Time on X or Contour, and retained selections are ignored there.

**Contour** has its own assignment form: single numeric X-axis and Y-axis boxes, optional Separate lines and Separate plots. No Time assignment is required. Selected percentiles or times/horizons automatically create panels. Separate plots adds factor-level or continuous-group panels. Separate lines overlays line-only contours for those conditions, distinguished by line type; filled surfaces are used when no Separate lines variable is assigned. Axis predictors and condition variables are held or varied explicitly; display roles do not refit models. Missing X or Y assignments leave the contour waiting. Plots use approximately square panels, with additional canvas space on the selected legend side. They use interpolated 65-by-65 continuous heat maps with numerically labeled equal-prediction contours and a continuous colour bar; tables use the specified predictor count per dimension. Native progress indicates completed contour work; it does not promise an estimated completion time. Each measure has its own table; merge across measures is unavailable. Confidence bounds appear in tables, not surface bands.

**Contour levels**, below Axis settings, is available only for contour plots. Number defaults to five equally spaced interior levels for each panel's finite prediction range. Common across figures is off by default; enabling it uses the same levels across all selected model/distribution/subgroup/component figures and slices for that outcome. Heat-map colours remain comparable across panels in each figure. Custom shows separate entries only for the selected outcomes; enter multiple comma-separated values or expressions in original outcome units, such as survival times 200, 400, 600 or probabilities 0.2, 0.5, 0.8. Probability levels must be between zero and one; other levels must be non-negative. Blank custom levels show a heat map without contour lines, or a waiting plot for Separate lines. Values outside a panel's prediction range produce no contour there. Predictor transformations control display coordinates and sampling; From/To bounds control the plotted prediction surface. Contour tables retain their equally spaced raw fitting-data grids and original units.

**Heatmap scale** provides Linear or Log (base 10) colour transformations and independent From/To limits for each selected outcome. Limits accept scalar expressions in original outcome units; blank limits use the finite prediction range within that figure (positive predictions for Log). The colour-bar range rounds outward to JASP pretty ticks on the selected scale, including its beginning and end. Entered From/To limits also round outward. Values beyond the rounded range use the end colours. Lifetime percentiles, median and mean share the Survival time colour controls. The controls are disabled for Separate lines, which draws line contours without a heatmap. Contour levels and table estimates remain in their original units. Contour panel captions stay on one line.

All module figures reserve additional top and right canvas space for tick labels, including Kaplan�Meier and Cox survival/risk/cumulative-hazard plots, Cox proportional-hazards and residual plots, and parametric/mixture figures; data-axis limits are unchanged.



**Reference values** is a full-width dropdown with Average, Default and Custom modes. Average uses frequency-weighted fitting-data means for unused numeric covariates and equal weights over every combination of unused factor levels. The original fitted model matrix is built for that reference grid and averaged on each parameter's linear-predictor/link scale before back-transformation. This is not an arithmetic average of response-scale predictions or a population-mixture survival distribution. Interactions, fitted transformations and polynomial bases are retained. Confidence intervals use joint parameter draws at the averaged design; confidence limits are never averaged. Default holds unused raw numeric predictors at zero and factors at their default fitted level. Default zero must lie in a transformation's domain; otherwise choose Average or valid Custom values. Custom shows a single Value row using the same input style as new-observation predictions. Entered cells fix those predictors; blank numeric cells use frequency-weighted fitting-data means and blank factor cells receive equal-weight link-scale averaging. Plotted/grouped predictors are omitted from Custom reference input and retain their assigned values. Assigned covariates is a separate dropdown for quantile-group or custom numeric line/panel values for both plot types. Relative-life comparisons use this same conditioning choice.

**Prediction interval**, below Confidence intervals, is independent and off by default. It shows a central fitted-distribution event-time range (default 95%) on absolute predictor-axis survival-time plots and tables. Endpoints are fitted lifetime percentiles. Individual event-time variability is included; parameter-estimation uncertainty is excluded. Existing confidence intervals describe uncertainty in the estimated prediction. Relative survival time, contour, probability, hazard and RMST do not acquire this range. Unbounded endpoints remain unbounded in tables and are not drawn.

**Observed data**, off by default, overlays unadjusted observed event times on absolute lifetime-versus-predictor figures. Censored observations are excluded from this point layer and are shown only through the independent Censoring events rug control. Categorical predictors use small deterministic horizontal jitter for observations; fitted estimates and their confidence intervals are slightly dodged together by prediction series. Time in Separate lines gives one shared event cloud; Time in Separate plots repeats it per percentile panel. In contour plots, Observed data shows the observed X/Y covariate pairs from the fitting data, including events and censored cases, for every outcome. Points repeat across time/percentile slices and follow Separate plots and Separate lines conditions. They use the selected axis transformations without jitter, stay within the displayed range, and do not change the fitted surface or axes. Time/percentile-x and relative-life standard figures ignore retained Observed data selections.

Optional **Censoring events** rug marks use an actual time axis: bottom for Time on X and left for lifetime on Y. Marks use the corresponding curve colours and add no extra censoring legend entries. They describe unadjusted follow-up. Relative-life and contour figures do not receive raw time rugs. Kaplan-Meier overlays require fixed factor profiles; Average or blank Custom entries for unused factors are ineligible. Time-axis rugs and KM curves respect the selected time range, and KM curves retain step values at the boundaries without extrapolating past observed support. Existing diagnostics are retained. Overview and Events are removed from Model predictions while their placement is considered separately.

**Axis settings** gives each numeric X-axis predictor its own transformation (Linear, Log or Model term) and From/To plotting bounds. Bounds accept scalar expressions in original predictor units; blank bounds use the fitting-data range (positive values for Log). Curves and uncertainty bands are computed over this range, observed overlays are restricted to it, and JASP pretty ticks round the displayed axes outward. Lifetime / Time on X retains its separate transformation and uses the Time grid for its range. Survival time Y scaling also applies to relative survival time; Probability Y scaling applies only to survival and failure probabilities. Contour mode shows only its X and Y predictor transformations and ranges; contour colours and levels retain outcome units. Contour predictor ranges round outward to JASP pretty ticks before computing the surface, so the heat map fills the complete displayed X/Y range. Raster cell edges are clipped to these fixed bounds and do not expand the axes again. Contour tables retain their original fitting-data grids. Categorical axes are not transformed. Log uses base 10. Times and percentiles in Separate lines or Separate plots retain their original values. Table grids and units do not change.

**Model term** displays a shared scalar transformation already used in fitting, with transformed-value ticks and an explicit axis title. For Arrhenius, source Celsius or Fahrenheit values are converted to Kelvin before displaying `1/(k_B T)` in inverse eV; this replaces the previous independent Inverse Kelvin display option. Standardization uses each model's original fitting-data mean and standard deviation. Conflicting transformations or standardization constants across displayed models, polynomial or spline terms, Eyring's multiple temperature terms, or transformations that cannot be inverted over the plotted range require Linear or Log instead. A transformed predictor axis does not guarantee a linear predicted-outcome curve.

Continuous line/panel labels use `variable = assigned value`, without group numbers or quantile-group prefixes. Explanatory captions are omitted from prediction images; option help and table footnotes describe the methods.

Prediction tables have direct predictor-value columns under **Variables** and a separate Time or Percentile column for evaluated curves. Mean and median tables have no evaluation column. Axis/line/panel roles are not printed as columns or embedded as `name = value` cell strings. Multiple predictor figures share one table per outcome; actual selected model/family/subgroup grouping is retained. Legends identify actual series and are omitted for a single series; held predictor values and factor averaging appear only in table notes. Average notes directly report sample-mean values for unassigned numeric predictors and equal-weight averaging of categorical predictor contributions. Default notes combine numeric zeros and default factor levels in one sentence; Custom notes identify actual fixed values and remaining averaging. Bounded legend size allowances add horizontal room for left/right legends and vertical room for top/bottom legends; None retains the base dimensions.


Time-axis lifetime evaluations use percentiles 0 through 100 (default steps 10). Curves use a smooth grid over the selected percentile range. Infinite lifetime percentiles remain in tables and are not drawn as finite points. Sequence From, Step and To accept expressions and are blank by default: From uses zero, To uses 100 for percentiles or maximum finite follow-up for times, and Step uses 10 or one tenth of that maximum follow-up. Changing From leaves the automatic Step and To unchanged; explicitly entered values persist. Show reference condition has been removed.


Categorical prediction ranges follow the same within-category dodge as estimates and confidence bounds. Predictor batches share one direct Average/Default note for predictors held fixed across the entire batch; predictors varied on any axis or by lines/panels are excluded from that fixed-value note. Invalid evaluation/conditioning input reports its underlying error; inactive prediction settings do not block unrelated statistics. Detailed uses finer ticks on survival/failure probability axes; other themes and numerical predictions retain their existing behavior. Custom input cells remain attached to their displayed predictor while the schema changes.


Prediction figures precede prediction tables, following the Outcome measures checkbox order: Survival time, Relative survival time, Survival probability, Failure probability, Hazard, Cumulative hazard, Restricted mean survival time. Merged time-based tables follow the lifetime tables. Default prediction-figure widths are 20% smaller; heights are unchanged. Survival time is time to the specified event: if that event is failure, the lifetime percentiles are times to failure. Percentile 50 is the median time to failure; 90 is the time by which 90% have failed, rather than the time at 90% survival.


The lifetime and time/horizon grids use the same controls with Time on X, in Separate lines, in Separate plots, or with Contour. All grid choices remain available. Moving Time off X selects Custom lifetime percentiles and Custom (relative) times; moving it back selects Equal intervals. Moving between lines and panels preserves the selected method. Entered counts, sequences and custom values are retained; loading saved settings does not reset their selected methods. Equal intervals defaults to 10 intervals, producing 11 values including both endpoints. Sequence places From, Step and To on one row. Custom lifetime percentiles default to 25, 50, 75. Custom (relative) time values default to 25, 50, 75 percent of maximum finite follow-up; they are evaluation times, not lifetime percentiles. Custom (absolute) accepts non-negative times/horizons; a blank uses those three follow-up fractions. Time-axis and mixture-component curves use smooth values across the selected grid range; lines, panels and contours use the chosen grid values as slices. Rounding affects generated time/horizon table values only. The Lifetime and Time blocks remain visible and are disabled when their outcomes/outputs are unused. The percentile grid is visible only when Percentiles is selected.


**Reference values** is a single dropdown (Average, Default, Custom); its one-row custom table appears directly below it and includes only unassigned model variables. The selector is disabled when all model variables are assigned. **Assigned covariates** is a separate full-width dropdown for numeric covariates in Separate lines or Separate plots, including contour conditions. Quantiles uses quantile-group raw means; its unlabeled integer field defaults to three groups. Custom opens an editable table with Add row and Remove row, one column per assigned numeric covariate. Each column is an independent list: partially blank columns use only entered values, wholly blank columns use their fitting-data sample means, and different columns may contain different numbers of values. All combinations define the line/panel conditions. Blank cells stay blank in the editor. Assigned factors continue to use their levels.


Assigned-covariate custom tables have no corner heading and label rows Level 1, Level 2, etc. **Group unique levels**, checked by default with limit 5, uses exact observed values for numeric Separate lines or Separate plots variables with at most that many unique values. These variables bypass quantile grouping; observed rows and their curve colours remain matched to their actual levels. Above the limit, or when unchecked, quantile grouping applies. This applies to both display roles, including contour conditions. Explicitly entered Custom values retain precedence; numeric X-axis grids are unchanged.

Prediction axes use JASP pretty ticks calculated after the plot layers are constructed. Numeric x and y limits span the outermost ticks and cover the visible curves, confidence/prediction bounds, observed points and censoring marks. Tick calculations use display coordinates for transformed axes, with tick positions converted back to the original scale; table values and model fits are unchanged. Lifetime-percentile x axes follow the selected grid range (default zero to 100), rounded outward to pretty ticks. Changing Sequence From/To or Custom percentiles therefore zooms the figure.


**Lifetime summaries** offers independent **Percentiles**, **Median**, and **Mean** checkboxes. Percentiles is selected by default; each selected summary produces its own figure and table for Survival time and, when available, Relative survival time. Percentile inputs and displayed labels use percentages from 0 to 100; the backend evaluates the corresponding probabilities. Median is the fixed 50th percentile; mean is expected lifetime over the whole fitted distribution. Neither needs evaluation values, and retained percentile settings are ignored when Percentiles is unchecked.

With **Lifetime / Time** on X, mean and median display one point with confidence bounds per real predictor stratum, with no X labels or percentile/time grid. With predictors on X, numeric predictors produce curves over their specified range and factors produce points at their levels. Real Separate lines and Separate plots still stratify these summaries; Lifetime / Time in those roles does not duplicate mean or median. Non-finite or unavailable means/medians produce an error on the affected figure while other selected summaries remain available. Relative mean and median use paired parameter draws for reference/current ratios and require finite summaries for both profiles.

Time / horizon settings continue to evaluate survival probability, failure probability, hazard, cumulative hazard, and restricted mean survival time. RMST remains the expected lifetime capped at the chosen horizon, distinct from the unrestricted mean. Contour plots and tables also support the selected mean and median on two numeric predictor axes, without percentile/time slices; contour level settings for Survival time apply to its selected Lifetime summaries. For Variables, prediction ranges and observed-event overlays apply to percentile, median and mean survival-time outputs against predictors. The prediction range describes individual event-time variability, including when displayed around a mean or median curve; it is separate from uncertainty in that mean or median. Mean and median ignore percentile slices in Separate lines or Separate plots. Censored observations remain available as separate rug marks. Observation inputs support individual event-time prediction ranges on mean/median plots.

**Connect x-axis levels**, above Observed data in Display, is checked by default and available when at least one factor is assigned to X-axis variables. It joins point estimates in factor-level order separately within each prediction series and panel. For example, Sex on X and Lifetime / Time in Separate lines connects the sexes independently for every selected lifetime percentile. Lines align with the dodged estimates and confidence bounds. Turning it off leaves the points and bounds. Numeric predictor curves and scalar Lifetime / Time summaries retain their existing display.

The **Kaplan-Meier** checkbox is disabled when the selected setup cannot provide a matching empirical overlay: no right censoring, no survival/failure probability plot against Lifetime / Time, continuous predictors in every interpreted model, or unfixed factor profiles. Average over unused factors and blank Custom factor cells do not define fixed empirical profiles. Assign factors to Separate lines/plots, choose Default references, or enter Custom factor levels to enable eligible factor-only models. With All models, one eligible model enables the checkbox and only eligible figures receive overlays. Merged distributions require every fitted distribution in the figure to be eligible. Availability is computed from the actual fitted models chosen for display, including Best AIC/BIC selections, reference values, observed profile support and the plotting time range. Retained checkbox selections are restored when the setup becomes available.


Logarithmic lifetime-percentile axes keep percentile labels in their original units. Narrow ranges use round JASP pretty values placed at logarithmic positions; wider ranges use conventional logarithmic breaks. Labels use only the decimal precision needed to distinguish adjacent ticks.
Merged prediction figures use separate visual keys: colours identify distribution/model/component context and predictor-line values; merged subgroups use line types for curves and point shapes for point plots, including mean/median against Lifetime / Time. If only one subgroup is represented, multiple merged distributions use types/shapes when predictor lines already use colours. With no predictor lines, distributions retain colour coding. Single-colour legends are suppressed while useful subgroup/distribution keys remain. Full model/line/subgroup combinations still group curves, confidence bands and dodged points; the display coding does not change estimates or reference conditioning. Continuous-predictor mean/median curves use line types. Empirical overlays and censoring/observed colours follow the same colour groups.

Case weights are positive integer frequencies: a row with weight 150 represents 150 identical units, including when censored. The fitting dataset is expanded to repeated units before model fitting, transformation bases (including polynomials and splines), and diagnostics. Data-derived numeric averages, assigned covariate quantile groups, and numeric standardization use this expanded sample. Dataset predictions and exports retain one value per original row. Blank numeric cells in Manual and Dataset predictions also use frequency-weighted fitting-data means. Explicit Custom values and Default reference levels keep their specified conditions.

Probability plots always compare the fitted conditional distribution with observation times adjusted to the frequency-weighted mean fitted model design within each stratum and subgroup. This automatic reference includes interactions and unselected factor effects; it is independent of the Predictions reference settings. Failure times and censoring bounds receive the same transformation. The axis says Adjusted time when predictor variation is removed, and Time when no adjustment is needed. Models without predictors retain their original plots.

**Stratify by** is selected by default and lists the fitted model variables. Factors are selected initially; continuous covariates are not. Selected factors use observed levels. Selected continuous variables use frequency-based **Quantiles** (default 3), except that **Group unique levels** uses individual observed values when there are at most the specified number of distinct values (default 5). These shared numeric settings are enabled whenever Stratify by is checked and apply to selected continuous stratifiers. Ties stay together, so fewer quantile groups can result. Membership uses original predictor values, including censored observations, before time adjustment. Empirical probabilities are then calculated within each stratum from adjusted times. Numeric variation within a quantile group is also adjusted.

Multiple selected variables form crossed strata; empty combinations are omitted. Strata without failures can show fitted curves and censoring marks, but have no empirical failure points. Unchecking Stratify by or all its variables pools observations and adjusts all remaining predictor effects, including factors. **Merge Plots Across: Strata** is checked by default, showing the selected strata in the same figure. Uncheck it to show each stratum in a separate plot without changing memberships or reference designs. Separate plots retain the adjusted-time and failure-probability ranges and axis ticks of the merged figure. Separately fitted subgroup models remain distinct.

When distributions or numbers of mixture components are merged, each fitted model has its own adjusted observations and identifying point symbols. Mixture diagnostics use the full mixture distribution; observations are not assigned to latent components. Curve confidence intervals hold the fitted observation adjustment fixed. A mixture or a distribution not matching the canvas need not produce a straight line. Some cure-fraction or extreme-tail profiles cannot be mapped to finite reference times; stratify by the responsible predictors or simplify the model.

**Density plot**, under Diagnostics, compares the fitted distribution with an observed histogram. It averages fitted densities over the observed predictor values using case weights. **Stratify by** uses factors by default; numeric covariates can be selected explicitly. The shared Quantiles and Group unique levels settings follow the probability-plot membership rules. Every selected observed stratum has a separate figure; unchecking Stratify by or all variables pools the sample. The curve and histogram use exactly the same observations and frequency weights in that stratum. **Merge Plots Across: Distributions** overlays distributions without pooling strata. Distributions overlays the selected distributions in different colours on one observed histogram within each subgroup; it is available when all distributions are displayed without model selection. Subgroups retain separate plots and observed data. **X-axis transformation** selects None or Log (default). Log plots display the density of log time, with curves multiplied by time and histogram bins computed on log time. **Observed data** is selected by default and available for right-censored data; histogram probabilities use Kaplan-Meier, retaining any unidentified tail mass. **Bin width type** offers Sturges, Scott, Doane, Freedman-Diaconis (default), or Manual with **Number of bins** (default 30). The fitted line spans the full observed time range, including the histogram bin edges. The Predictions time grid does not restrict this diagnostic. Its own **Confidence intervals** checkbox, above Observed data, optionally shows pointwise bounds from joint parameter draws and is off by default; its default level is 95%. The Predictions confidence checkbox does not control this plot. Colour palette, legend and theme settings still apply.
